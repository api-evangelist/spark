To enable wide-scale community testing of the upcoming Spark 4.1.0 release, the Apache Spark community has posted a Spark 4.1.0-preview3 release. This preview is not a stable release in terms of either API or functionality, but it is meant to give the community early access to try the code that will become Spark 4.1.0. If you would like to test the release, please download it, and send feedback us
